# همه‌خوان | OmniReader Android

اپلیکیشن اندرویدی فارسی برای دریافت فایل از طریق «باز کردن با…» و اشتراک‌گذاری فایل از برنامه‌های دیگر.

## قابلیت‌های فعلی
- رابط فارسی و راست‌چین درون Android WebView
- دریافت فایل‌های ورودی با Android Intent و نمایش نام، نوع و اندازهٔ فایل
- پشتیبانی از انتخاب چند فایل در Intentهای اشتراک‌گذاری
- جست‌وجوی جریانی (chunk-based) در فایل‌های متنی: TXT، CSV، TSV، JSON، XML، HTML، MD، LOG، YAML، INI و SQL
- خواندن فایل ورودی از طریق URI مجاز Android؛ بدون درخواست دسترسی سراسری حافظه
- ساخت خودکار APK آزمایشی با GitHub Actions

## محدودیت‌های فعلی
این نسخه هنوز یک مبدل/استخراج‌کنندهٔ همه‌قالب‌ها نیست. تشخیص PDF، Word، Excel، MDB/ACCDB، ZIP، RAR و 7z به‌معنای استخراج و جست‌وجوی محتوای آن‌ها نیست؛ برای این قالب‌ها باید موتور تخصصی اضافه و آزمایش شود. جست‌وجوی متنی فعلی به پسوندهای فهرست‌شده در بالا محدود است.

پذیرش فایل بزرگ به‌تنهایی تضمین پردازش موفق آن نیست. سرعت و امکان جست‌وجو به حافظهٔ دستگاه، سرعت ذخیره‌ساز، مجوز دسترسی URI و ساختار فایل بستگی دارد. فایل‌های آرشیوی نیز در نسخه‌های بعدی باید با محدودیت حجم استخراج و محافظت در برابر آرشیوهای مخرب پردازش شوند.

## ساخت APK
1. وارد زبانهٔ Actions مخزن GitHub شوید.
2. گردش‌کار Build OmniReader APK را انتخاب کنید.
3. پس از موفقیت اجرا، فایل OmniReader-debug-apk را از بخش Artifacts دریافت کنید.

فایل خروجی فعلی، APK نوع debug است و برای انتشار عمومی هنوز امضای release و آزمون روی دستگاه‌های واقعی لازم است.

## حریم خصوصی
برنامه فقط URIهایی را می‌خواند که کاربر از طریق Android به آن می‌دهد و برای خواندن فایل‌ها درخواست دسترسی سراسری حافظه نمی‌کند. فایل‌های ورودی برای نمایش در WebView از مسیر داخلی برنامه ارائه می‌شوند.
