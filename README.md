# همه‌خوان | OmniReader Android

اپلیکیشن اندرویدی برای بازکردن فایل‌ها از طریق Android Sharesheet و «باز کردن با…».

## وضعیت
این مخزن در حال آماده‌سازی است. فایل‌های پایه Gradle، Manifest و workflow ساخت APK اضافه شده‌اند. برای ساخت APK باید کد Activity و فایل رابط وب در مسیر `app/src/main/assets/index.html` نیز اضافه شوند.

## Build
از GitHub Actions، گردش‌کار **Build OmniReader APK** را اجرا کنید. خروجی APK در بخش Artifacts قرار می‌گیرد.

## Privacy
برنامه باید فقط URI انتخاب‌شده توسط کاربر را بخواند و از دسترسی سراسری حافظه استفاده نکند.
